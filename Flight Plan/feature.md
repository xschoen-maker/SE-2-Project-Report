

## System Features

### 1. Semester Flight Plan

Students get a checklist of career tasks and experiences for each semester.

- **US-01:** As a student, when a semester begins, I want to see my assigned tasks and experiences so that I can make time for them along with my classes.
- **US-02:** As a student, when I review my flight plan, I want to see which semester it belongs to so that I work on the right checklist.

### 2. Career Preparation Tasks

The checklist includes practical activities such as creating a resume, drafting a cover letter, setting up Handshake and LinkedIn, preparing an elevator pitch, applying for an internship, and doing a mock interview.

- **US-03:** As a student, when I am getting ready to apply for an internship or job, I want to see the tasks on my checklist so that I know what to finish before applying.
- **US-04:** As a student, when I return to the checklist, I want to see which tasks are complete so that I can focus on what I still need to do.

### 3. Career Experiences

The system lists experiences such as career fairs, career training, volunteering, mentoring, and connecting with professionals.

- **US-05:** As a student, when I want to gain experience outside of class, I want to see the experiences in my flight plan so that I can find ways to learn new skills and meet professionals.
- **US-06:** As a student, when I look through my checklist, I want each item labeled as a task or an experience so that I know what kind of activity to plan for.

### 4. Completion Recording

Students submit proof of their work, such as a file, link, or written response. The item counts as complete as soon as they submit it.

- **US-07:** As a student, when I finish a task or experience, I want to submit the requested proof so that I can show I completed it.
- **US-19:** As a student, when I submit my proof, I want the item marked complete right away so that I can see it is finished on my checklist.

### 5. Progress Overview

The dashboard shows how many checklist items students have completed and their overall progress.

- **US-08:** As a student, when I check my progress during the semester, I want to see how many items I have completed out of the total so that I know how much I have left to do.

### 6. Points

Checklist items show point values, and the dashboard shows the student's available points.

- **US-09:** As a student, when I review my checklist, I want to see how many points each item is worth so that I know what I can earn by completing it.
- **US-10:** As a student, when I check my dashboard, I want to see my available points so that I can keep track of my rewards.

### 7. Event Calendar and Details

Upcoming events show the date, time, location, and whether the student is registered. Some events also have a description.

- **US-11:** As a student, when I am deciding which career events to attend, I want to see when and where each event takes place and what it is about so that I can choose events that interest me and fit my schedule.
- **US-12:** As a student, when I want to see more events than the dashboard lists, I want to open the event calendar so that I can find other events to attend.

### 8. Event Registration

Students can sign up for events that offer registration through the event listing or a related flight plan experience.

Signing up for an event does not mark the related experience complete.

- **US-13:** As a student, when I find an event I want to attend, I want to register for it so that I have a spot at the event.
- **US-14:** As a student, when I review an upcoming event, I want to see whether I am registered so that I know whether I still need to sign up.

### 9. Checklist Search and Organization

Students can search, filter, and sort the items in their full flight plan.

- **US-15:** As a student, when I am looking for a particular checklist item, I want to search by its name so that I can find it quickly.
- **US-16:** As a student, when I review a long checklist, I want to filter and sort the items so that I can narrow down what to work on next.

### 10. Notifications

Students can read and clear notifications on the dashboard.

- **US-17:** As a student, when I open my dashboard, I want to see flight plan notifications so that I can keep up with updates about my activities.
- **US-18:** As a student, when I have read my notifications, I want to clear them so that new updates are easier to spot.
